# Security

Pawse stores an optional YouTube Music session on your phone (in the iOS Keychain or Android Keystore) and talks only to the music and lyrics services it uses; there is no Pawse server.

If you find a vulnerability, for example a way to read that session, please report it privately with GitHub's [private vulnerability reporting](https://github.com/thenetaji/pawse-music/security/advisories/new) instead of opening a public issue. Expect a reply within a week. Fixes ship in the next release, and the advisory is published once people have had a chance to update.

Only the latest release receives fixes.
